# Documentation: DINO ViT-S16 Unsupervised Clustering for Balinese Statues

This document explains the workflow, methodology, and implementation details of the unsupervised clustering project for Balinese traditional statue images.

## Project Overview
This project implements an automated visual classification system for Balinese statues using the **DINO ViT-S16** self-supervised model. The goal is to group more than 10,000 images into meaningful clusters based on visual similarity without requiring manual labels.

---

## 1. Pipeline Workflow

The project follows a 5-stage pipeline as outlined in the research methodology:

### Stage 1: Preprocessing (`src/data_loader.py` & `preprocess.py`)
- **Input**: Raw images of Balinese statues (Dewa, Wanara, Raksasa, etc.) in `data/raw/`.
- **Process**: 
    - Resizing images to 256x256 pixels.
    - Applying center-crop to 224x224 pixels (ViT compatible).
    - Normalization based on ImageNet statistics.
- **Output**: Preprocessed tensors stored in `data/processed/` and a `manifest.csv`.

### Stage 2: Feature Extraction (`src/feature_extractor.py` & `extract_features.py`)
- **Model**: `dino_vits16` (Vision Transformer Small with 16x16 patch size).
- **Process**: The model acts as a "backbone" to extract deep visual features (768-dimensional vectors) for each image.
- **Output**: Feature matrix saved as `features/resized_256x256/features.npy`.

### Stage 3: Dimensionality Reduction (`src/dim_reducer.py`)
- **Method**: **UMAP** (Uniform Manifold Approximation and Projection).
- **Process**: Reducing the 768D feature vectors into **2D embeddings**. This is crucial for efficient clustering and clear visualization.
- **Output**: Embeddings saved in `embeddings/resized_256x256/`.

### Stage 4: Unsupervised Clustering (`src/clustering.py`)
- **Algorithm**: **K-Means Clustering**.
- **Configuration**: Set to 8 clusters (based on initial taxonomy of Balinese statues).
- **Metrics**: `
    - **Silhouette Score**: Measures how similar an object is to its own cluster compared to other clusters.
    - **Optimal K**: Automatically calculated using the Elbow and Silhouette methods.
- **Output**: Cluster assignments in `clusters/resized_256x256/`.

### Stage 5: Visualization & Inspection (`visualize_clusters.py` & `visualize_comparison.py`)
- **Scatter Plot**: Visualizes the clusters in a 2D UMAP space.
- **Comparison Grid**: Generates a montage of 6 random samples per cluster to visually verify consistency.
- **Output**: PNG files and sample folders in `plots/resized_256x256/`.
